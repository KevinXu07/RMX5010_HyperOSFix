# 模块自带安装器（1.7.0，2026-11-05）

1.7.0 的模块 zip 里多了 `install.sh` 和 `installer/`（ZygiskNext 1.5.2、
LSPosed 2.2.1(7912)、Sense 1.38 release 签名版），安装模块时自动部署，
已经装过的组件跳过。

## KernelSU 的 install.sh 语义（实测）

用两个 dummy 模块在 RMX5010 / SukiSU 40900 上测得：

- 模块里**有** `install.sh` 时，ksud 只把 `module.prop` 和 `install.sh`
  解到 `$MODPATH`，其余文件**不会**自动展开；工作目录是 `/dev/tmp`，
  环境变量为 `$ZIPFILE`（原始 zip 路径）、`$MODPATH`
  （`/data/adb/modules_update/<id>`）、`$TMPDIR=/dev/tmp`。
- 因此 `install.sh` 必须自己 `unzip "$ZIPFILE" -d "$MODPATH"`，否则模块装完
  只剩 module.prop。
- 普通安装（无 install.sh）时 ksud 会把 `system/system_ext` 提升到模块根
  目录，并留下 `system/system_ext -> ../system_ext` 符号链接（system-as-root
  适配）。走 install.sh 时这一步不一定发生，脚本里自己补，保证相机库的
  挂载路径与 1.6.9 完全一致。
- `ksud module install <嵌套 zip>` 可以在 install.sh 里调用（实测成功），
  嵌套模块按普通路径展开。

## install.sh 做的事

1. busybox `unzip -o -q` 展开整包，失败即中止；
2. `chmod 0755 *.sh`；
3. 提升 `system/system_ext` 并建符号链接；
4. 校验载荷：相机 APK 必须 193,164,793 B，`rmx5010_fod_bridge.ko`、
   `service.sh` 必须存在，否则中止（避免半残模块开机）；
5. `/data/adb/ksud module install` 装 ZygiskNext（`zygisksu`）、
   LSPosed（`zygisk_lsposed`），目录已存在则跳过；
6. `pm install` 装 Sense，已安装则跳过；
7. 失败时把对应包复制到 `/sdcard/Download/rmx5010_installer/`。

日志：设备端 `/data/local/tmp/rmx5010_installer.log`，同时输出到 KSU
管理器的安装界面。

## Sense 签名

- 旧的 `Sense-1.38.apk` 是 release 构建（非 debuggable），但用 Android Debug
  证书签名。签名不影响运行时性能，1.7.0 仍按用户要求换成独立 release 密钥
  （`E:\code\modify\Sense\keystore\sense-release.jks`，不在本仓库内）。
- 签名变了就不能覆盖安装：手机上已有旧 Sense 的，先卸载
  `com.zephiel.sense`，再装新 APK/重装模块，然后在 LSPosed 里重新启用
  Sense 并重勾作用域。LSPosed 的 `lspctl` 只支持 `status`/`stop`，无法
  脚本化启用模块和作用域，这一步只能手点。

## 实测记录（2026-11-05）

- `ksud module install rmx5010_fod_bridge-1.7.0-camera-full.zip`：7.5 s 完成，
  rc=0；`modules_update` 里 239 个文件与源码树逐一比对（名称 + 大小）完全一致，
  `system/system_ext` 符号链接与 1.6.9 安装结果相同。
- 重启后模块 1.7.0 生效：`boot.log` 触控/QESDK/insmod/IFAA/游戏帧率均正常，
  `/product/priv-app/OplusCamera/OplusCamera.apk` 仍是 193,164,793 B /
  mtime 0，相机预览持续出帧（camera service 预览帧率日志）。
- LSPosed：冷启动时 watchdog 在 uptime 12 s 重启 zygote，
  `early_start.log` 记录 `after restart hooks present`，Sense 的 system_server
  钩子已安装。
- 本机三个组件都已存在，所以嵌套安装/`pm install` 走的是“跳过”分支；
  嵌套安装机制本身用 dummy 模块验证过，未在真机上演练重装 LSPosed（避免
  已知的 `zygisk_lsposed` 被改动后 lspd SIGSEGV 问题）。
