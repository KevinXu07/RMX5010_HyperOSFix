## 5. 明确不做/不适用

- **LTPO 模块**：用户确认系统已生效，不做。
- **OP13 IOplusVibrator / 800~2400 振幅 / 双马达 RTP**：RMX 是标准 `IVibrator` + qcom HV 单 LRA，硬件语义不同；用“私有 ID 映射 + VibrationScaler 系数”替代。
- **双马达专属 SRT 波形**：RMX 单马达，不适用。

## 6. 建议下一步

1. 完成第 1 节的用户/硬件验证（IFAA、LHDC、充电、音频、触感、采样率、抬起亮屏）。
2. 如果确认要 Sense 作为控制面：先解决三处冲突，再添加“移植修复”页。
3. 功能优先级：§22/23 通知 → §24 核心破解 → §33/§44 稳定性 → §39/§40 游戏与调度。
4. 触感全套 RTP 先不做；根据实际手感决定是否值得为 RMX 重做波形。
5. §36/§37/§41/§42 属于体验增强，放后。
