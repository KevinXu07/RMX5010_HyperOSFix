# 镜像改动总表（haotian 主线，2026-11-14 整理）

这份表回答一个问题：**当前刷在手机上的分区镜像，相对来源（小米 donor / RMX5010 原厂）改了什么**。

- 只列镜像里的改动。KSU 模块（`kernel-src/ksu-module`）和 Sense（LSPosed）在运行时做的覆盖另列在第 3 节，作为对照。
- 详细根因与验证见各行"记录"列。修复清单编号对应 `docs/修复清单与状态矩阵.md`。

## 3. 运行时覆盖（模块 / Sense，不在镜像里）

镜像之外，KSU 模块在开机时覆盖了这些镜像内容。排查问题时要注意：**镜像里的文件不一定是实际生效的文件**。

| 覆盖目标 | 方式 | 文件 |
|---|---|---|
| `/product/overlay/DevicesAndroidOverlay.apk`、`DevicesOverlay.apk` | bind-mount 补丁版 | `post-fs-data.sh`、`overlay/` |
| `/product/etc/displayconfig/display_id_4630947008615494291.xml` | bind-mount 按面板实测重建的亮度表 | `post-fs-data.sh`、`overlay/`（1.7.18） |
| `/product/priv-app` | tmpfs + overlayfs：OplusCamera 6.070.45 补丁版、ProviderStub、ColorOSGalleryStub | `camera_fix.sh` |
| `/odm/lib64`、`camera_unit_config`、`/system/lib64` 若干库 | overlay / bind | `camera_fix.sh` |
| `/system_ext/lib64` 两个音频策略库 | bind-mount | `post-fs-data.sh`、`audio/` |
| `/odm/etc/permissions/fake_camera_extensions.xml` | bind 空 `<permissions/>` | `wechat_fix.sh` |
| `/mi_ext/product/{ai/taiyi,etc/cust_features}` | tmpfs + bind 到 `/product` 对应目录 | `post-fs-data.sh` |
| vendor seccomp policy（QESDK/QAPE） | bind-mount | `qesdk_fix.sh` |
| `ro.surface_flinger.set_touch_timer_ms`、取色器两项 prop | `ksud resetprop` | `post-fs-data.sh` |
| 内核 | insmod `rmx5010_fod_bridge.ko`、7 个 millet 模块 | `service.sh`、`millet_fix.sh` |

## 4. 构建可复现性

- `scripts/build_h19_full.sh` 只覆盖到 **2026-10-25** 的配方（odm 身份/账号、vendor 账号/NFC/LTPO、system 信号/MTP/NFC、product DPI/刷新率/亮度/灵动岛，system_ext 直通）。
- 之后的镜像改动要在它的产物上依次叠加：
  1. `scripts/build_h19_fingerprint_features.sh`（product：指纹特性/FOD 属性/device_features）
  2. `scripts/build_h19_vendor_fp_permissions.sh`（vendor：生物识别特性声明）
  3. `scripts/build_vendor_odm_fp_props.sh`（vendor property_contexts 重标 + odm `vendor.fingerprint.cali=1`）
  4. `scripts/build_odm_fp_hal.sh`（odm：指纹 HAL）
  5. `scripts/build_system_ext_patches.sh`（system_ext：只用 miui-services 指纹桩，**不要**再换 Settings）
  6. 11-02 原厂化：product 两个 Devices overlay 换回 donor 原版，灵动岛补丁那一步不做。
- 相机内容（product `priv-app/OplusCamera`）来自相机终版回读镜像，没有从零构建的脚本。
- 实际出包是用**实机回读**镜像（`port_sources/readback_images/`，2026-11-02）加 11-02 原厂化得到的，不是上面这条脚本链跑出来的。所以要保证与手机一致，以整包 `out/full_image_haotian/images/` 为准。
- 每次刷写的镜像哈希记录在仓库外的 `E:\code\modify\haotian_port_h19\metadata\provenance.txt`（到 2026-10-26）；11-02 原厂化的记录见 `docs/Settings与overlay原厂化_SenseHook_20261102.md` 和整包 `README_zh.md`。
